# Changelog

## v0.0.3 - 2026-11-25

- Refresh main-menu icons and fanart with original artwork.
- Add archive-search icon and fanart fallback while preserving programme artwork.
- Keep plugin fanart available while navigating and use it when programme artwork is missing.
- Use the station logo for archive programmes without their own thumbnail.

## v0.0.2 - 2026-11-25

- Align with the original add-on version 1.2.0: add request timeouts and improve EPG parsing and scheduled generation.
- Write XMLTV programme times in UTC and guard channel-number changes against collisions.
- Save channel visibility after applying a group and add IPTV Merge integration.
- Retain the fork's FFmpegDirect playlist settings.

## v0.0.1 - 2026-11-24

- Initial release of the personal fork, based on the original add-on version 1.1.9 by waladir.
- Add archive search and remote access through Kodi JSON-RPC.
- Show programme artwork and station logos, including in IPTV exports.
- Support archive downloads with the optional `script.stream.saver` add-on.
- Estimate archive playback start and preserve Kodi resume and programme metadata.
